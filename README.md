# 🎃 Pasapalabra Informático - Edición Halloween 👻

Juego interactivo del Rosco de Pasapalabra con temática técnica de informática (redes, sistemas operativos, arquitectura, Linux, seguridad, bases de datos y desarrollo web) ambientado en Halloween.

## 🚀 Demo Online
Acceso directo desde cualquier dispositivo (PC o móvil):
👉 **https://raaulbarriios.github.io/pasapalabra-informatico/**

## ✨ Características
- **Rosco de 27 letras**: Preguntas informáticas de dificultad media-alta (empieza por o contiene cada letra).
- **Diseño Halloween**: Paleta morada/naranja, murciélagos animados, telarañas y efectos sonoros interactivos.
- **Multidispositivo**: Interfaz responsive adaptada a pantallas táctiles móviles y teclados de PC.
- **Cursos soportados**: 1º SMR, 1º ASIR, 2º ASIR y Profesores.
- **Ranking global online**: Clasificación en tiempo real sin necesidad de servidor local ni configuración extra.
- **Récords únicos por jugador**: Se conserva la mejor marca histórica de cada nombre.
